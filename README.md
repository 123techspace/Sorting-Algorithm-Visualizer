# Sorting Algorithm Visualizer

An interactive web application that demonstrates how different sorting algorithms work through visual animations. It helps users understand sorting techniques by observing how elements are compared, swapped, and arranged during execution.

## 🚀 Live Demo

[View Project Repository](https://github.com/123techspace/Sorting-Algorithm-Visualizer/tree/main)

## ✨ Features

- **Interactive Visualization:** Visualize sorting algorithms through animated representations.
- **Multiple Algorithms:** Explore Bubble Sort, Insertion Sort, Selection Sort, and Quick Sort.
- **Step-by-Step Execution:** Understand how elements are compared and rearranged during sorting.
- **User-Friendly Interface:** Simple and intuitive design for learning and experimentation.

## 🧮 Sorting Algorithms

| Algorithm | Best Case | Average Case | Worst Case |
|---|---|---|---|
| Bubble Sort | O(n) | O(n²) | O(n²) |
| Insertion Sort | O(n) | O(n²) | O(n²) |
| Selection Sort | O(n²) | O(n²) | O(n²) |
| Quick Sort | O(n log n) | O(n log n) | O(n²) |

## 💻 Getting Started

### Prerequisites

A modern web browser such as Google Chrome, Firefox, or Microsoft Edge.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/123techspace/Sorting-Algorithm-Visualizer.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Sorting-Algorithm-Visualizer
   ```

3. Open `index.html` in your browser to run the application.
